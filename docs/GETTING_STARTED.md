# Getting started

Open the checked-in TokenEntryDemo.xcodeproj with Xcode 26.6+. Select a simulator and Run. The package can be added independently using its repository URL and TokenEntry product. Use Swift tools 6.3 and iOS 18 minimum deployment.

The project uses a local package reference for development; consumers use the remote repository. No sibling checkout is required. Run swift test for platform-neutral editing logic; use the demo UI test scheme for simulator behavior.
