# Customization

Use the tokenContent builder for text, SF Symbols, avatars, badges, and selection styling. Keep tokens identifiable by domain identity rather than displayed text. Customize placeholder and spacing. The playground exposes avatar, spacing, disabled, and RTL controls.

Use scalable fonts and semantic colors. Avoid imposing fixed token heights; long labels should wrap or deliberately truncate in your own content. Validation belongs to the consumer's onSubmit closure: reject invalid submissions or append tokens with a validation indicator. The component does not request Contacts permissions.
