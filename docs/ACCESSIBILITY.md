# Accessibility

Every token is a button with a supplied accessible label, selected trait, and Delete accessibility action. The text field has an accessible placeholder, native keyboard handling, and Dynamic Type support. Layout mirrors for right-to-left environments. No custom motion is introduced; system behavior respects platform preferences.

Consumers are responsible for contrast and text sizing inside custom token content. Verify VoiceOver, maximum Dynamic Type, hardware keyboards, marked-text input methods, and custom avatars on target devices. Automated tests are not a substitute for assistive-technology review.
